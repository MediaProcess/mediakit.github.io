# MediaKit

The MediaKit product website, built with HTML and CSS. No JavaScript, framework, or build step is required.

## Pages

- `index.html` — Product overview and features.
- `support.html` — Frequently asked questions and support contact.
- `privacy.html` — Privacy Policy.
- `terms.html` — Terms of Service.

Shared styles and images are stored in `assets/`.

## Local preview

From this directory, run:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Open `http://127.0.0.1:4173/`, or open the HTML files directly in a browser.
